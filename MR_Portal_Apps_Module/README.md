# MR Portal Apps Module

This is the standalone MR Portal Apps project. It contains the routes under
`pages/MR_Portal_Apps` and the shared components, utilities, constants, styles,
and assets required by those routes.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000/` to render MR Home directly. The original route is
also available at `http://localhost:3000/MR_Portal_Apps/MRHome`.

For a production run:

```bash
npm run build
npm run start
```
